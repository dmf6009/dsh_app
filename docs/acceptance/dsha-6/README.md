# DSHA-6 UI/UE acceptance evidence (Diff page)

Automated acceptance artifacts for the two UI/UE review blockers (P1-1 Confirm
Dialog accessibility, P1-2 Diff responsive layout), generated by the headless
Electron harness in `scripts/capture/` against the BUILT renderer with a stub
`window.desktop` (no real runtime, no git, no writes outside this directory).

**Hard-assertion gate (no false-green):** `scripts/capture/main.cjs` does not
just record bounds — for every scenario it runs explicit assertions and exits
**non-zero** if ANY requirement is unmet, reporting the scenario and the
field/values. `gate-summary.json` records the run: `21/21` scenarios pass with
an empty `failures` array. A deliberately injected failure was verified to flip
the gate to `FAIL` with exit code 1.

**Scope / honesty note:** these are **Xvfb/headless captures** of the real
built renderer. They verify layout bounds, focus placement, no page-level
horizontal scroll, and busy-gating in a synthetic DOM. They are **NOT** a
real-desktop 100%/125% DPI human walkthrough — that remains an explicit
regression boundary (see the issue reply), to be confirmed on a real display
before final UI/UE sign-off.

```
npm run build

```

`.bounds.json`.

## Assertions enforced per scenario

- **All**: `noPageHScroll === true` (page-level horizontal scroll forbidden;
  Monaco scrolls only inside its `overflow:hidden` host), recorded via
  `pageScrollWidth`/`clientWidth`.
- **normal / binary / revert**: toolbar visible; all `.diff-actions` button
  rects pairwise non-overlapping.
- **binary**: binary placeholder (`.diff-status`) shown.
- **empty**: empty state (`.diff-empty`) shown.
- **revert-stage1**: dialog open AND `activeIsCancel === true` (focus on 取消).
- **revert-stage2**: dialog open, focus NOT on cancel, active text is the
  confirm label.
- **revert-busy-guard**: after pressing confirm then dispatching Escape and a
  backdrop click — dialog still open (`dialogOpen`), `dialogBusy` true,
  `confirmDisabled` true, `hasSpinner` true (not dismissible while busy).
- **revert-cancel-restore**: after cancel — dialog closed and focus restored to
  the trigger button (`activeText === "恢复此文件…"`).

`.bounds.json` also records every `.diff-actions` button rect for the
non-overlap assertion and the viewport size.
